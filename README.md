\# CinemaTickets



Навчальний проєкт з дисципліни «Конструювання програмного забезпечення». Варіант № 9: продаж квитків у кінотеатрі.



\## Склад рішення

\- `CinemaTickets.Core` — логіка предметної області (бібліотека класів)

\- `CinemaTickets.App` — консольний застосунок (введення й виведення)\[cite: 20]



\## Вимоги

.NET SDK 8.0 або новіший, Git\[cite: 20].
